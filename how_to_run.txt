======================================================================
  CineNova - Step-by-Step Guide to Run the Complete Stack
======================================================================

Follow these instructions to start and run the CineNova cinema ticket booking platform:

----------------------------------------------------------------------
Prerequisites
----------------------------------------------------------------------
1. Node.js (v18 or higher installed)
2. MySQL Server running on localhost:3306

----------------------------------------------------------------------
1. Database Schema & Setup
----------------------------------------------------------------------
Ensure MySQL is active, then initialize the database:
- Open a terminal in the project root directory ('cinenova').
- Run the setup script to initialize the 'cineplex_db' database and tables:
    .\setup_db.bat
  (Alternatively: cd server && npm run db:setup)

----------------------------------------------------------------------
2. Run the Node.js Express Backend API
----------------------------------------------------------------------
The Node Express server runs on port 8080. It handles all REST APIs, WebSockets for seat locking, email OTP verification, and payment processing:
- Open a terminal window.
- Navigate to the 'server' directory:
    cd server
- Install dependencies (if not already installed):
    npm install
- Start the server:
    npm start

----------------------------------------------------------------------
3. Run the React Vite Frontend
----------------------------------------------------------------------
The frontend is a React SPA built with Vite on port 5173:
- Open a new terminal window.
- Navigate to the 'frontend' directory:
    cd frontend
- Install dependencies (if not already installed):
    npm install
- Start the development server:
    npm run dev

- Access the platform by opening your browser to:
    http://localhost:5173/

----------------------------------------------------------------------
System Port Mapping Summary
----------------------------------------------------------------------
* Frontend Web Client:   http://localhost:5173
* Express Backend API:   http://localhost:8080
* MySQL Database Port:  3306
======================================================================
