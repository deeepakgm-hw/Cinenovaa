======================================================================
  CineNova - How to Run Frontend & Backend in VS Code
======================================================================

Follow these simple steps to run and develop the entire application stack:

----------------------------------------------------------------------
Prerequisites
----------------------------------------------------------------------
1. Node.js (v18 or higher recommended)
2. MySQL Server running on localhost:3306
3. VS Code

----------------------------------------------------------------------
Step 1: Database Initialization
----------------------------------------------------------------------
Make sure your MySQL database is initialized:
- Open a terminal in the project root directory
- Run the setup script:
    .\setup_db.bat

----------------------------------------------------------------------
Step 2: Configure and Start the Node.js Express Backend
----------------------------------------------------------------------
The Node.js server runs the entire API and real-time WebSockets on port 8080:
1. Open a terminal in VS Code and navigate to the 'server' directory:
    cd server
2. Make sure server/.env exists and has your database and SMTP credentials.
3. Start the server:
    npm start

----------------------------------------------------------------------
Step 3: Start the React Frontend
----------------------------------------------------------------------
The React web application provides the cinema booking user interface on port 5173:
1. Open a new terminal in VS Code and navigate to the 'frontend' directory:
    cd frontend
2. Start the Vite development server:
    npm run dev
3. Open http://localhost:5173 in your web browser!
